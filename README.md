# Calculation Tool

Webapplicatie voor het automatisch berekenen van productiecalculaties.

## Functionaliteiten

- Importeren van DXF bestanden
- Nesting analyse
- Berekenen materiaalgebruik
- Berekenen bewerkingen
- Kostenoverzicht
- Adminrechten instellingen

## Technologie

Frontend:
- React
- Vite
- Zustand

Backend:
- ASP.NET Web API
- .NET Framework 4.8

Database:
- Ridder IQ
